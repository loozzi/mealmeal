# MealMeal v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây web app MealMeal: chụp ảnh hoặc mô tả bữa ăn, AI ước tính dinh dưỡng, lưu trên máy người dùng, theo dõi theo ngày bằng lịch vòng tròn so với mục tiêu calories, và xuất card chia sẻ.

**Architecture:** Một project Next.js (App Router). Mọi màn hình là client component đọc ghi IndexedDB qua Dexie. Một API route duy nhất `POST /api/analyze` gọi model qua OpenAI SDK, có giới hạn lượt gọi. Toàn bộ phép tính (ngày, dinh dưỡng, TDEE, trạng thái vòng tròn) là hàm thuần trong `src/lib`, không phụ thuộc React hay IndexedDB.

**Tech Stack:** Next.js bản stable mới nhất, TypeScript strict, Tailwind CSS, Dexie + dexie-react-hooks, zod, openai, @upstash/ratelimit + @upstash/redis, html-to-image, Vitest + fake-indexeddb, Playwright. Package manager: npm.

**Spec:** `docs/superpowers/specs/2026-11-17-mealmeal-design.md`. Đọc toàn bộ spec trước khi bắt đầu. Plan này quyết định tên file, chữ ký hàm và test; spec quyết định hành vi. Khi plan không nói tới một chi tiết hành vi, làm theo spec. Ký hiệu "spec §6.5" là mục 6.5 của spec.

## Global Constraints

- Toàn bộ chữ trên giao diện là tiếng Việt. Tên biến, tên hàm, commit message bằng tiếng Anh.
- API key chỉ ở server. Không biến môi trường nào có tiền tố `NEXT_PUBLIC_`.
- Server không lưu và không log ảnh hay mô tả bữa ăn. Chỉ log mã lỗi và thời gian xử lý.
- `DateKey` (`"YYYY-MM-DD"`) luôn tạo từ `getFullYear()/getMonth()/getDate()` của giờ máy. Cấm dùng `toISOString()` để lấy ngày.
- Tổng dinh dưỡng không bao giờ lưu vào database; luôn tính bằng các hàm trong `src/lib/nutrition.ts`.
- Chỉ làm tròn lúc hiển thị, qua các hàm trong `src/lib/format.ts`.
- Không truy cập `window`, `navigator`, `indexedDB` lúc render phía server. Trang nào dùng `useSearchParams` phải bọc trong `<Suspense>`.
- Thiết kế cho chiều rộng 360–430px; trên desktop nội dung nằm trong cột giữa `max-w-[480px]`. Vùng bấm tối thiểu 44×44px. Tôn trọng `env(safe-area-inset-bottom)`.
- Số hiển thị kiểu Việt Nam (`1.450`, `0,5`), dùng `tabular-nums`.
- Tuần bắt đầu từ thứ Hai.
- Database Dexie tên `mealmeal`, version 1. Không đổi cấu trúc bảng ngoài những gì plan mô tả.
- Trước khi dùng API của Next.js, Dexie, OpenAI SDK, Upstash, html-to-image: kiểm tra tài liệu bản hiện hành. Nếu API thực tế khác với plan, làm theo tài liệu và giữ nguyên hành vi.
- Mỗi task kết thúc bằng: `npm run typecheck && npm run lint && npm test` đều qua, rồi commit.

- Produces (`dates.ts`):
  - `type DateKey = string`
  - `toDateKey(d: Date): DateKey`
  - `parseDateKey(k: string): Date | null` — trả về nửa đêm giờ máy; `null` nếu sai định dạng hoặc ngày không tồn tại
  - `todayKey(now?: Date): DateKey`
  - `addDays(k: DateKey, n: number): DateKey`
  - `addMonths(k: DateKey, n: number): DateKey` — giữ ngày trong tháng, kẹp về ngày cuối tháng nếu tháng đích ngắn hơn
  - `weekOf(k: DateKey): DateKey[]` — 7 ngày, phần tử đầu là thứ Hai
  - `monthGrid(k: DateKey): (DateKey | null)[]` — các ngày của tháng chứa `k`, chèn `null` ở đầu và cuối để độ dài chia hết cho 7, cột đầu là thứ Hai
  - `isFuture(k: DateKey, today: DateKey): boolean`
  - `resolveDateParam(raw: string | null | undefined, today: DateKey): DateKey` — `raw` không hợp lệ hoặc là ngày tương lai thì trả `today`
  - `nowTime(now?: Date): string` — `"HH:mm"`
- Produces (`format.ts`):
  - `formatInt(n: number): string` — làm tròn, ngăn nghìn bằng dấu chấm
  - `formatGrams(n: number): string` — `n < 10`: một chữ số thập phân với dấu phẩy, bỏ phần `,0`; còn lại: số nguyên
  - `parseDecimal(s: string): number | null` — chấp nhận dấu phẩy hoặc dấu chấm thập phân, cắt khoảng trắng; `null` nếu không phải số hữu hạn
  - `formatDate(k: DateKey): string` — `"17/11/2026"`
  - `formatDayLong(k: DateKey): string` — `"Thứ Ba, 17/11"`; tên thứ: Chủ Nhật, Thứ Hai … Thứ Bảy
  - `formatMonth(k: DateKey): string` — `"Tháng 11/2026"`
  - `WEEKDAY_SHORT: readonly string[]` — `["T2","T3","T4","T5","T6","T7","CN"]`

  Các hàm định dạng tự ghép chuỗi, không dùng `Intl` để kết quả không phụ thuộc môi trường.
